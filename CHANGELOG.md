# Changelog / 更新记录

## English

### 0.1.0 — 2026-10-05

- Added a configurable CLI for dual ASR, voice clustering, comparison, forced alignment and original-language Markdown.
- Added original-size frame extraction, OCR and an optional local InternVL adapter.
- Added ordered loopback-only translation with proxy/redirect blocking and explicit pending review.
- Added 4K rolling study captions, timed images/glossary notes, original audio copy and packet/PCM/video-span QA.
- Added shared editorial MD/Word/PPT export, portable figure assets and aspect-fitted pictures.
- Published bilingual setup, pitfalls, architecture, source references, validation and an agent skill.
- Added synthetic contract tests, privacy checks and Windows/Linux CI; kept third-party licenses and generic historical recipes.
